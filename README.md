# Ecommerce Data Analytics Project

## 📌 Overview
This project demonstrates an **end-to-end Data Analytics workflow**:
- MySQL database design with schema and sample data
- Python analysis using Pandas, SQLAlchemy, Matplotlib, and Seaborn
- Visual reports saved in the `reports` folder (Top Products, Monthly Revenue, Customer Orders)

## ⚙️ Setup Instructions
1. Clone the repository
2. Install dependencies (`pip install -r requirements.txt`)
3. Run schema and insert data in MySQL
4. Execute Python scripts to generate reports

## 📊 Reports
- Top Products (bar chart)
- Monthly Revenue (line chart)
- Customer Orders (bar chart)
